Skills demo

Copy each prompt into GitHub Copilot Chat in VS Code, in order. The keywords in each prompt (DEV-200, company, ZCONFIG_CONS, ATC, NAST ...) make Copilot load the matching skill by itself. Tick what you see in the answer.

Before you start

  1. Connect DEV-200 in ABAP FS.
  2. In the chat bar choose Local mode (selector at the bottom of the chat). In Copilot mode skills are off while the chat folder is DEV-200.
  3. Customizations → Skills lists the 7 abap-* skills from %USERPROFILE%\.agents\skills.
  4. Start one new chat and run the steps in order; later steps use the class from step 3.
  5. Alternative that needs no mode switch: run the same prompts in the Copilot CLI (copilot in a terminal) from any local folder while VS Code and ABAP FS stay connected. It uses the same skills and the abap-fs MCP server.

BADI boilerplate

One prompt creates a complete BADI with an implicit enhancement: interface, enhancement spot and BADI definition, implementing class, BADI implementation with filter, the enhancement in your FORM, and the exit row. Copilot does it by running report ZBADI_GENERATOR (skill abap-badi-boilerplate).

Before you start

  1. Same setup as the skills demo: DEV-200 connected, chat in Local mode (or the Copilot CLI from a local folder).
  2. Use your own unused dev ID and exit ID. The generator creates the local package $<PREFIX>_<DEV_ID>; a name that was used before can fail with “already versioned”.
  3. Write the prompt the way you would ask a colleague. If something required is missing (exit fields, RICEF), Copilot asks before it changes anything; just answer.
  4. The run creates objects and a ZCONFIG_EXIT1 row (client-independent, not on a transport). There is no delete tool, so use test names.

Why a skill for this

Creating a BADI by hand means SE24, SE18, SE19, an implicit enhancement and an SM30 row, in the right order. The skill turns that into one report run with a dry run first and SQL checks at the end. It asks for what only you can know (exit fields, RICEF) instead of inventing it.
