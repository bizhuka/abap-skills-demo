ABAP Skills Demo

Copy each prompt into GitHub Copilot Chat in VS Code, in order. The keywords in each prompt (DEV-200, company, ZCONFIG_CONS, ATC, NAST ...) make Copilot load the matching skill by itself. Tick what you see in the answer.

Before you start

  1. Connect DEV-200 in ABAP FS.
  2. In the chat bar choose Local mode (selector at the bottom of the chat). In Copilot mode skills are off while the chat folder is DEV-200.
  3. Customizations → Skills lists the 7 abap-* skills from %USERPROFILE%\.agents\skills.
  4. Start one new chat and run the steps in order; later steps use the class from step 3.
  5. Alternative that needs no mode switch: run the same prompts in the Copilot CLI (copilot in a terminal) from any local folder while VS Code and ABAP FS stay connected. It uses the same skills and the abap-fs MCP server.
